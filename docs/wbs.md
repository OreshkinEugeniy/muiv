# ИСР по V-модели (Булычев, 2022, с. 8–10)
| Этап | Работы | Ветка | Роль |
|---|---|---|---|
| 1 | Сбор требований, критерии приёмки | stage/01-requirements | Аналитик |
| 2 | Техническое задание | stage/02-documentation | Аналитик |
| 3 | Архитектура, модель данных, алгоритм | stage/03-architecture | Архитектор |
| 4 | Реализация CLI и хранения | stage/04-implementation | Разработчик |
| 5 | Модульные, интеграционные и приёмочные проверки | stage/05-testing | Тестировщик |
| 6 | Инструкция, выпуск, сопровождение | stage/06-deployment | Сопровождение |

Роли проектные, в учебном проекте один участник. Владелец администрирует репозиторий; участники с правом записи создают ветки и PR; читатель публичного репозитория читает и клонирует. Защита main и обязательная проверка PR рекомендуются после первоначальной публикации; фактические настройки нужно подтвердить отдельно. Права на отдельные ветки не возникают автоматически из названия ветки.
