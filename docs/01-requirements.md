# 1. Планирование и анализ требований
Цель: упорядочить личные задачи по срокам. Пользователь добавляет название, дату и приоритет 1–3, просматривает список и завершает задачи. Просрочка выделяется. Данные сохраняются между запусками. Критерий приёмки: ближайшие незавершённые задачи выше остальных; при равных сроках выше больший приоритет.
